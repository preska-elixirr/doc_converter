# Project instructions

Read `docs/PROJECT_CONTEXT.md` before non-trivial changes.

Maintain documentation in the same task as implementation changes: update the
owning feature docs, relevant `docs/methods_report/` API entries, and discovery
or status pages when behavior or scope changes. Document limitations and actual
verification results; do not claim unrun checks. Preserve the frontmatter
convention in `docs/index.md`.

Keep processing local, preserve sources, and commit outputs without overwriting.
Enforce file eligibility and safety in Rust, not only in the frontend. Add
meaningful regression coverage for processing and privacy changes.
